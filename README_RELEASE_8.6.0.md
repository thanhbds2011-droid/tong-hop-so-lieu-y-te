# Ứng dụng Phòng Y tế v8.6.0

Bộ production thống nhất **Tổng hợp số liệu + Chuyển viện + Tử vong**.

## Bắt đầu

1. Đọc `HUONG_DAN_TRIEN_KHAI_8.6.0.md`.
2. Không dán `firebase-yte-rules-fragment-v8.6.0.json` thay toàn bộ Firebase Rules.
3. Nếu Rules hiện tại đã đúng fragment Y tế đã cung cấp thì không cần sửa Rules.
4. Deploy source lên GitHub Pages.
5. Chạy `TEST_8.6.0.md` sau deploy.

## HSBA

Bộ release này **không chứa `firebase-database.rules.json` toàn hệ thống** và không thay node HSBA.
